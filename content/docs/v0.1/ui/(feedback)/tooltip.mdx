## Coming from Figma

In Figma the Tooltip uses **Type** (8 position variants), **Size** (2X-Small / Small / Large), **Dark Mode**, and **Tail**. In code:

- **Position**: not a variant; use Radix's `side` (`top` / `right` / `bottom` / `left`) and `align` props on `Tooltip.Content`. See the Position example below.
- **Dark Mode**: the `variant` prop (`dark` | `light`).
- **Size**: the `size` prop (`xsmall` | `small` | `medium`). The naming differs from Figma (Figma's 2X-Small ≈ `xsmall`).
- **Tail**: the arrow is always rendered by `Tooltip.Content`.

## API Reference

This component is based on the Radix UI Tooltip primitives. Refer to their [documentation](https://www.radix-ui.com/primitives/docs/components/tooltip) for the API reference.

### Tooltip.Content

Supports all of Radix Tooltip Content props and adds:

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"dark"` \| `"light"` | `"dark"` |
| `size` | `"medium"` \| `"small"` \| `"xsmall"` | `"small"` |
