## API Reference

### Divider.Root

This component is based on the `<div>` element and supports all of its props. And adds:

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"line"` \| `"line-spacing"` \| `"line-text"` \| `"content"` \| `"text"` \| `"solid-text"` | `"line"` |
