## Installation

<Steps>
  <Step>
    ### Install the following dependencies:

    <Tabs items={['npm', 'pnpm', 'yarn']}>

        ```bash
        npm install react-day-picker@8.10.1
        ```
      </Tab>
      <Tab value="pnpm">
        ```bash
        pnpm add react-day-picker@8.10.1
        ```
      </Tab>
      <Tab value="yarn">

        yarn add react-day-picker@8.10.1
