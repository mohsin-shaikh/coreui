## API Reference

This component is based on the [Radix UI Select](https://www.radix-ui.com/primitives/docs/components/select) primitives. Refer to their documentation for the API reference.

### Select.Root

Supports all of Radix Select Root props and adds:

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default"` \| `"compact"` \| `"compactForInput"` \| `"inline"` | `"default"` |
| `size` | `"medium"` \| `"small"` \| `"xsmall"` | `"medium"` |
| `hasError` | `boolean` | |
