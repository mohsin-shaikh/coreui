## Installation

<Steps>
  <Step>
    ### Install the following dependencies:

    <Tabs items={['npm', 'pnpm', 'yarn']}>
      <Tab value="npm">
        ```bash
        npm install @radix-ui/react-checkbox
        ```
      </Tab>
      <Tab value="pnpm">
        ```bash
        pnpm add @radix-ui/react-checkbox
        ```
      </Tab>
      <Tab value="yarn">
        ```bash
        yarn add @radix-ui/react-checkbox
        ```

    </Tabs>
