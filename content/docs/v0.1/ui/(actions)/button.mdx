## API Reference

### Button.Root

This component is based on the `<button>` element and supports all of its props. And adds:

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"primary"` \| `"neutral"` \| `"error"` | `"primary"` |
| `mode` | `"filled"` \| `"stroke"` \| `"lighter"` \| `"ghost"` | `"filled"` |
| `size` | `"medium"` \| `"small"` \| `"xsmall"` \| `"xxsmall"` | `"medium"` |
| `asChild` | `boolean` | |

### Button.Icon

The `Button.Icon` component is polymorphic, allowing you to change the underlying HTML element using the `as` prop.

| Prop | Type | Default |
| --- | --- | --- |
| `as` | `React.ElementType` | `div` |
