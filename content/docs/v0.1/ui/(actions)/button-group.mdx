## API Reference

### ButtonGroup.Root

This component is based on the `<div>` element.

| Prop | Type | Default |
| --- | --- | --- |
| `size` | `"small"` \| `"xsmall"` \| `"xxsmall"` | `"small"` |
| `asChild` | `boolean` | |

### ButtonGroup.Item

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | |

### ButtonGroup.Icon

The `ButtonGroup.Icon` component is polymorphic, allowing you to change the underlying HTML element using the `as` prop.

| Prop | Type | Default |
| --- | --- | --- |
| `as` | `React.ElementType` | `div` |
