  [coreui-nextjs-typescript-starter](https://github.com/mohsin-shaikh/coreui-nextjs-typescript-starter)

  template** on GitHub and start building.
</Callout>

<Steps>
  <Step>
    ### Initialize a NextJS Project

    If you don't already have a Next.js project set up, you can follow the official [Next.js setup guide](https://nextjs.org/docs/app/getting-started/installation) to create a new project quickly.
  </Step>
  <Step>
    ### Make sure you have Tailwind CSS v4 installed

    Follow [these instructions](https://tailwindcss.com/docs/installation/framework-guides/nextjs) if you don't have Tailwind CSS v4 installed in your project. You just need to have a `globals.css` file. **Note:** Tailwind CSS v4 doesn't require a config file by default.
  </Step>
  <Step>
    ### Add the CoreUI styles

    <Tabs items={['CLI', 'Manual']} defaultIndex={1}>
    <Tab value="CLI">

    **Coming soon.** A CLI that writes the stylesheet into your project for you is on the way. Until then, use the manual steps.

    </Tab>
    <Tab value="Manual">

    Include these styles in your main CSS file where Tailwind is imported:

    <ComponentSource
      src="styles/coreui.css"
      title="app/globals.css"
      prepend={"@import 'tailwindcss';\n\n"}
      append={`\n/* CoreUI Body Styles */
  body {
    background: var(--color-bg-white-0);
    color: var(--color-text-strong-950);
    font-family: Inter, Arial, Helvetica, sans-serif;
    margin: 0;
    padding: 0;
  }\n`}
    />

    **Note:** The above code includes the complete CoreUI design system with colors, typography, shadows, animations, and dark mode support. You can also get this CSS content by running the CLI command.

    That's all! Now you have all CoreUI tokens.

    </Tab>
    </Tabs>
  </Step>
  <Step>
    ### Add the required utils

    1. Go to [cn](/docs/v0.1/utils/cn) page and setup the utility in your project.
    2. Go to [tv](/docs/v0.1/utils/tv) page and setup the utility in your project.
    3. Go to [recursiveCloneChildren](/docs/v0.1/utils/recursive-clone-children) page and setup the utility in your project.
    4. Go to [Polymorphic](/docs/v0.1/utils/polymorphic) page and setup the utility in your project.
  </Step>
  <Step>
    ### Add the icon library

    CoreUI uses [Remix Icon](https://remixicon.com).

    <Tabs items={['npm', 'pnpm', 'yarn']}>
      <Tab value="npm">
        ```bash
        npm install @remixicon/react
        ```
      </Tab>
      <Tab value="pnpm">
        ```bash
        pnpm add @remixicon/react
        ```
      </Tab>
      <Tab value="yarn">
        ```bash
        yarn add @remixicon/react
        ```
      </Tab>
    </Tabs>
  </Step>
  <Step>
    ### Set up the Inter font
    Include Inter font from 'next/font/google':

    ```tsx title="app/layout.tsx" lineNumbers
    import { Inter as FontSans } from 'next/font/google'; // [!code ++]
    import './globals.css';
    import { cn } from '@/utils/cn';

    const inter = FontSans({ // [!code ++]
      subsets: ['latin'], // [!code ++]
      variable: '--font-sans', // [!code ++]
    }); // [!code ++]

    export default function RootLayout({ children }) {
      return (
        // [!code ++]
        <html lang="en" className={cn(inter.variable, 'antialiased')}>
          <body>{/* ... */}</body>
        </html>
      );
    }
    ```

    **Note for Tailwind CSS v4:** Font configuration is handled via CSS variables in the `@theme` block, so no additional config file setup is needed.
  </Step>
  <Step>
    ### Add dark mode (optional)

    All you need to do to enable dark mode in your app is add the `dark` class to your root element.

    ```tsx title="app/layout.tsx" lineNumbers
    export default function RootLayout({ children }) {
      return (
        // [!code ++]
        <html lang='en' className='dark'> 
          <body>{/* ... */}</body>
        </html>
      );
    }
    ```

    **Note:** With Tailwind CSS v4, dark mode classes are automatically included when using our `@theme` configuration.

    I recommend [next-themes](https://github.com/pacocoursey/next-themes) package for an easy dark mode toggle in your app.

  </Step>
  <Step>
    ### That's all

    Now you can start adding components to your app. You can begin by adding a [Button](/docs/v0.1/ui/button) first.
  </Step>
</Steps>
